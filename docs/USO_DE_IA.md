# Registro de uso de Inteligencia Artificial

## Herramienta

ChatGPT (OpenAI).

## Finalidad

Se utilizó como apoyo para estructurar el caso del TPI, proponer una versión inicial con problemas de diseño observables, explorar alternativas de refactoring, redactar documentación técnica, diseñar casos de prueba y revisar consistencia con la consigna.

## Prompt principal utilizado

> "Quiero que resuelvas el TPI de Metodología, te voy a pasar las consignas y contexto para que puedas resolverlo y entregarme un zip con todo lo necesario. Además quiero hacerlo con mi compañero Ignacio Figueroa."

La consigna oficial, materiales de Metodología de Sistemas II y modelos aportados se usaron como contexto del intercambio.

## Validación realizada

- Se ejecutaron pruebas automatizadas sobre la versión inicial y la refactorizada.
- Se agregó una prueba específica de equivalencia antes/después.
- Se verificó la existencia de los archivos, commits y tags requeridos en el repositorio local.
- La documentación técnica fue contrastada con los conceptos de calidad interna/externa, deuda técnica, SOLID, Clean Code, refactoring seguro y code review trabajados en la asignatura.

## Alcance y responsabilidad

La IA funcionó como asistente de productividad. La defensa oral debe realizarse con voz propia y los integrantes deben comprender y poder justificar cada decisión, clase, prueba y refactoring incluido en la entrega.
