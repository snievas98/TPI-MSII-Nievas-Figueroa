# Evidencias complementarias

- `demo_inicial.png` / `.txt`: ejecución visible de la versión inicial.
- `demo_refactorizada.png` / `.txt`: ejecución visible de la versión final.
- `tests_ok.png`: captura reproducible de la suite automatizada.
- `resultado_tests.txt`: salida textual de las pruebas.
- `git_historial.png`: historial por etapas utilizado como evidencia en el informe.
- `git_log.txt` y `git_tags.txt`: respaldo textual del historial y tags preparados durante la construcción.

Las imágenes son evidencia de apoyo. La verificación principal puede reproducirse directamente desde el código con `python -m unittest discover -s tests -v` y con los comandos Git indicados en `docs/PUBLICAR_EN_GITHUB.md`.
